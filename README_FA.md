# RZ Music AI — نسخه اولیه PWA

## امکانات فعلی
- رابط واکنش‌گرا برای دسکتاپ و موبایل
- قابلیت نصب به‌صورت PWA پس از میزبانی روی HTTPS
- جست‌وجوی آهنگ در Last.fm و دریافت آهنگ‌های مشابه
- لینک جست‌وجوی هر آهنگ در Spotify
- ذخیره API Key در localStorage مرورگر

## پیش‌نیاز
یک API Key رایگان Last.fm از این آدرس بسازید:
https://www.last.fm/api/account/create

سپس در اپ، بخش «تنظیمات اتصال Last.fm» را باز کرده و کلید را ذخیره کنید.

## اجرا
برای آزمایش محلی، فایل‌ها را روی یک وب‌سرور محلی اجرا کنید؛ باز کردن مستقیم index.html ممکن است Service Worker را فعال نکند.
مثلاً با Python:
`python -m http.server 8000`
سپس:
`http://localhost:8000`

## انتشار رایگان
می‌توانید فایل‌ها را در GitHub Pages یا Cloudflare Pages منتشر کنید. برای نصب PWA روی دستگاه‌ها، سایت باید از HTTPS ارائه شود.

## محدودیت‌ها
- این نسخه موسیقی را داخل خودش پخش نمی‌کند؛ لینک Spotify را باز می‌کند.
- پخش کامل و کنترل صف Spotify با حساب رایگان از طریق API تضمین‌شده نیست.
- Last.fm پیشنهادهای مشابه را ارائه می‌دهد؛ کیفیت و موجود بودن نتایج به داده‌های آن بستگی دارد.
- API Key در مرورگر ذخیره می‌شود؛ این روش برای نمونه شخصی مناسب است، نه سرویس عمومی چندکاربره.
