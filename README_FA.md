# RZ Mood — PWA با MusicAtlas

## امکانات
- رابط واکنش‌گرا با پنل‌های شیشه‌ای (Glassmorphism)
- زبان فارسی و انگلیسی با تغییر RTL/LTR
- چهار تم: RZ Mood (پیش‌فرض)، Ocean Glass، Violet Night و Sunset
- کشف هنرمندان و آهنگ‌های مشابه با MusicAtlas
- لینک Spotify، بازکردن صفحه منبع در تب جدید، اشتراک‌گذاری و کپی عنوان
- دانلود فقط وقتی منبع، لینک مستقیم دانلود ارائه کند؛ برنامه لینک Spotify را به فایل صوتی تبدیل یا محدودیت‌های پخش را دور نمی‌زند.
- PWA برای ویندوز و اندروید پس از میزبانی HTTPS

## راه‌اندازی
در تنظیمات MusicAtlas، کلید API خود را وارد کنید. کلید در localStorage مرورگر ذخیره می‌شود. برای استفاده شخصی/آزمایشی مناسب است؛ برای اپ عمومی به سرور واسط امن نیاز دارید.

## انتشار به‌روزرسانی
تمام فایل‌های داخل این پوشه را در ریشه مخزن GitHub Pages آپلود و فایل‌های قبلی را جایگزین کنید. سپس Commit changes بزنید و سایت را با Ctrl+F5 تازه‌سازی کنید. نسخه Service Worker نیز به v3 تغییر کرده تا کش قبلی کنار گذاشته شود.

## محدودیت دانلود
MusicAtlas و Spotify جست‌وجو/اطلاعات موسیقی را فراهم می‌کنند، نه مجوز دانلود فایل صوتی. دکمه دانلود فقط برای نتیجه‌ای فعال می‌شود که خودش یک `download_url` یا `audio_url` مستقیم ارائه کند. در غیر این صورت لینک صفحه منبع باز می‌شود.
